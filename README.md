# Calculator

A simple console-based calculator application built with C#.

## Description

This project is a basic calculator that allows the user to:

* Enter two numbers.
* Perform addition, subtraction, multiplication, and division.
* Handle invalid number input.
* Handle division by zero.
* Perform multiple calculations without restarting the application.

## Technologies Used

* C#
* .NET
* Console Application

## How to Run

1. Clone the repository.
2. Open the project in Visual Studio.
3. Build the solution.
4. Run the application.

The calculator will ask you to enter two numbers and choose an operator.

## Supported Operations

```text
+  Addition
-  Subtraction
*  Multiplication
/  Division
```
